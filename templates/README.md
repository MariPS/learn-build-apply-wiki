# Templates

Reference copies of the page types the skill maintains. The agent writes
these from the schemas in `SKILL.md`; these files are here for when you
want to create a page by hand, or to see the shape at a glance.

`project.md` and `project-doc.md` are the two project-wiki page types;
`scripts/add_project.py` creates a whole project folder from them.

Study topic pages are generated by `scripts/add_module.py` and are not
duplicated here.
